# Published AetherPlay Games

This repository is an immutable publication surface for completed benchmark seasons.

- Do not hand-edit published submissions.
- Add submissions only through the trusted `aetherplay publish` command after a complete season matrix closes.
- Preserve source, production build, and manifest together.
- Never place runtime credentials, raw model traces, vote exports, unpublished prompts, or evaluator internals here.
- A correction creates a new release and submission identifier; it does not rewrite an old artifact.
